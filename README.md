# Portfólio profissional

## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio profissional pessoal como atividade da disciplina **Design Profissional**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **Cruzeiro do Sul**.

O portfólio apresenta informações sobre minha formação, conhecimentos técnicos, competências comportamentais, áreas de interesse e atividades acadêmicas desenvolvidas durante meu processo de formação em Tecnologia da Informação.

## Objetivos

* Apresentar minha formação acadêmica e trajetória de aprendizado na área de Tecnologia da Informação.
* Reunir informações sobre meus conhecimentos técnicos e competências comportamentais.
* Apresentar minhas áreas de interesse profissional.
* Criar uma presença profissional na internet.
* Desenvolver uma página web com organização, acessibilidade, responsividade e identidade visual profissional.
* Utilizar o projeto como parte das atividades da disciplina **Design Profissional**.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias básicas para desenvolvimento web:

* **HTML5** — estrutura e organização do conteúdo.
* **CSS3** — estilização, layout, responsividade e identidade visual.
* **Markdown** — documentação do projeto por meio deste arquivo README.

Não foram utilizados frameworks ou bibliotecas externas no desenvolvimento do portfólio.

## Estrutura do portfólio

A estrutura principal do projeto está organizada da seguinte maneira:

```text
portfolio-profissional/
│
├── index.html
├── style.css
├── README.md
├── LICENSE
│
└── assets/
```

### Arquivos principais

* `index.html` — contém a estrutura e o conteúdo principal do portfólio.
* `style.css` — contém os estilos visuais da página.
* `README.md` — documentação do projeto.
* `LICENSE` — arquivo referente à licença do projeto.
* `assets/` — pasta reservada para imagens, documentos e outros recursos que possam ser adicionados posteriormente.

## Como executar localmente

Para executar o portfólio localmente, não é necessário instalar frameworks ou bibliotecas adicionais.

### Passo 1 — Baixar ou clonar o projeto

Faça o download dos arquivos do projeto ou clone o repositório para o computador.

### Passo 2 — Abrir o projeto

Abra a pasta do projeto no **Visual Studio Code (VSCode)**.

A estrutura deve conter, no mínimo:

```text
index.html
style.css
```

### Passo 3 — Abrir o arquivo HTML

Abra o arquivo `index.html` em um navegador para visualizar o portfólio.

O arquivo `index.html` já possui a referência ao arquivo `style.css`, fazendo com que os estilos sejam carregados automaticamente.

### Execução com extensão Live Server

Também é possível utilizar uma extensão de servidor local, como o **Live Server**, no VSCode para facilitar a visualização e atualização da página durante o desenvolvimento.
